# Git Command Cheat Sheet

## 1. Check Git Version

Command:
git --version

Purpose:
Check the installed Git version.

## 2. Configure Username

Command:
git config --global user.name "YeYintAung"

Purpose:
Set your Git username.

## 3. Configure Email

Command:
git config --global user.email "your-email@gmail.com"

Purpose:
Set your Git email address.

## 4. Display Configuration

Command:
git config --list

Purpose:
Display Git configuration information.

## 5. Clone Repository

Command:
git clone repository-url

Purpose:
Download a GitHub repository to your computer.

## 6. Check Status

Command:
git status

Purpose:
Display the current file status.

## 7. Add Files

Command:
git add .

Purpose:
Add all modified files to the staging area.

## 8. Commit Changes

Command:
git commit -m "Your message"

Purpose:
Save changes locally with a commit message.

## 9. Upload to GitHub

Command:
git push

Purpose:
Upload local commits to GitHub.

## 10. Download Updates

Command:
git pull

Purpose:
Download and merge updates from GitHub.

## 11. View Commit History

Command:
git log --oneline

Purpose:
Display project commit history.

## 12. Create Branch

Command:
git branch branch-name

Purpose:
Create a new branch.

## 13. Switch Branch

Command:
git checkout branch-name

Purpose:
Switch to another branch.

## 14. Merge Branch

Command:
git merge branch-name

Purpose:
Merge another branch into the current branch.
